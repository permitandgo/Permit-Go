# Permit & Go Website

GitHub Pages-ready static website.

## Upload instructions
1. Unzip this folder.
2. Upload all files to the `permitandgo` GitHub repository.
3. Ensure the homepage file is named `index.html`.
4. In GitHub, go to Settings → Pages and publish from the main branch.
5. Submit this sitemap in Google Search Console:
   https://permitandgo.github.io/permitandgo/sitemap.xml
